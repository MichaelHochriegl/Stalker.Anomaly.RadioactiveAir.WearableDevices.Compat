# WearableDevices - RadioactiveAir Compatibility

Compatibility mod that brings the RadioactiveAir display over to the WD devices.

## Installation and upgrading

1. Install both parent mods normally.
2. Install this folder as a separate MO2 mod, with gamedata at its root, below
   both
3. In MO2, verify that RadioactiveAir supplies toxic_air.script and that this
   addon has no file conflicts with either parent. Restart the game.
4. Select the existing WD watch Filter time/Dynamic mode or Vektor Toxic
   Air/Dynamic status mode. Normal device power/visibility rules apply.
